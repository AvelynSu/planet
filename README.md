# planet


planet : 여러개의 토큰을 가지고 있는 지갑
tokenInfo : 토큰의 순수한 정보 (커스텀 토큰 개념)
tokenBalance : 토큰의 잔액 정보 (tokenInfo 를 가지고 있음)

current : 지금 앱에서 다루고 있는 지갑
balances : current 에 속해있는 토큰들 정보
